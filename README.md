# Portfólio — João Pedro Rocha

Site pessoal em HTML, CSS e JavaScript puro (sem frameworks, sem instalação).

## Estrutura

```
Portf-lio-/
├── index.html        # página principal (todo o conteúdo)
├── css/
│   └── style.css     # visual, cores e responsividade
├── js/
│   └── script.js     # fundo de constelação, animações e menu
├── img/
│   └── foto.jpg      # foto de perfil
├── cv/
│   └── Curriculo_Joao_Pedro_Rocha.pdf   # currículo (botão do site)
└── README.md
```

## Como abrir

Dê dois cliques no `index.html`.

## Como editar

| O que mudar | Onde |
|---|---|
| Textos, links, e-mail, redes sociais | `index.html` |
| Cor de destaque | `css/style.css` → variável `--color` (no começo) |
| Foto | substitua `img/foto.jpg` (use uma imagem quadrada) |
| Fundo de constelação | `js/script.js` (topo do arquivo) |

## Publicar (GitHub Pages)

Settings → Pages → Source: *Deploy from a branch* → escolha a branch e a pasta `/ (root)`.
